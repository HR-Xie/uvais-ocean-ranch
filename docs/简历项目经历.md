## 项目简介

UVAIS 海洋牧场智能调度系统：面向水下养殖场景的多角色 AI Agent，基于 LlamaIndex + LangChain 构建混合检索 RAG 管线与 ReAct 工具调用闭环，集成安全联锁机制实现从环境感知到作业派单的自动化决策。前端基于 Streamlit 搭建海洋主题交互界面，支持流式对话与 PDF 工单导出。

---

## 项目经历描述

### 1. 混合检索 RAG 知识引擎

基于 LlamaIndex 框架设计多路混合检索管线：加载 BGE-M3 双向量嵌入模型，构建 Dense 语义检索（1024 维向量）+ BM25 关键词检索双路召回，经 RRF 倒数排序融合截断 Top-20 候选集，再由 BGE-Reranker Cross-Encoder 精排至 Top-5 送入 DeepSeek 大模型生成回答。知识库覆盖 10 篇海洋 SOP 文档共 59 个语义节点，支持 MD5 去重增量入库与 SentenceSplitter 自适应分块。使用 Ragas 搭建忠实度、相关性、上下文精确率、上下文召回率 4 维自动化评估体系，通过对比实验迭代优化检索策略，最终精确度达 85.1%、召回率达 83.3%，较初始纯 Dense 方案提升 37 个百分点。

### 2. ReAct Agent 多工具调度

基于 LangChain `create_agent` 构建 ReAct Agent，封装知识检索、海况校验、视觉检测、空间导航、安全联锁 5 个工具函数，实现从环境查询、风险评估到工单派发的自动决策闭环。设计 3 层中间件体系对 Agent 行为进行约束：`monitor_tool` 记录每次工具调用日志并兜底异常、`log_and_limit_tools` 限制单轮最多 5 次工具调用防止无限循环、`report_prompt_trigger` 运行时动态切换工单生成专用提示词。通过系统提示词精细化控制工具调用纪律，强制知识类问题必须走 RAG 检索而非模型记忆回答，消除幻觉风险。

### 3. 前端交互与工程化

前端基于 Streamlit 搭建，自定义 300+ 行 CSS 实现海洋主题（浅蓝渐变背景、自定义聊天气泡、毛玻璃固定输入栏、角色快捷指令芯片）。使用 Playwright 编写 9 场景浏览器自动化测试，覆盖知识检索、工具调用、安全联锁、多轮对话、工单生成全流程。支持 Markdown → PDF 工单导出（CJK 字体），通过 `st.download_button` 一键下载。工程侧实现 LLM 单例工厂支持 DeepSeek / Qwen / OpenAI 热切换，解决 Windows 环境下 httpx 异步客户端 SSL 证书验证导致的连接故障，保障流式对话稳定性。
