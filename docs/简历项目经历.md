基于 LlamaIndex 设计多路混合检索 RAG 管线，融合 Dense 语义检索与 BM25 关键词检索，经 RRF 倒数排序融合后由 Cross-Encoder 精排，配合 DeepSeek 大模型生成回答。使用 Ragas 搭建 4 维自动化评估体系，通过对比实验优化检索策略，最终精确度达 85.1%、召回率达 83.3%，较初始方案提升 37 个百分点。
 
基于 LangChain 构建 ReAct Agent，封装知识检索、海况校验、视觉检测、空间导航、安全联锁 5 个工具函数，实现从环境感知到作业派单的自动决策闭环。设计 3 层中间件体系对 Agent 行为进行约束：工具调用日志与异常兜底、调用次数硬限流、运行时 Prompt 动态切换，确保 Agent 输出稳定可控。
 
知识库侧实现 MD5 去重增量入库与语义分片，消除全量重建开销；前端基于 Streamlit 搭建海洋主题交互界面，支持流式对话与 PDF 报告导出。
